# Configurable UDP
The goal of this project is to design a rust module that creates a framework
to your own packet handling protocol on top of a UDP connection. This means
you can design your own protocol from packet structure for a TCP like layer
on top of UDP to more fine grained scenarious were you would want lesser
heart beat packets for performance reasons.
